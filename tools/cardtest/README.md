# CARDTEST

Self-checking graphics-card test CDs for 86Box-Next guests (DOS, Windows 95/98/Me/NT 4/2000),
plus the host tools that drive test VMs and read their results. See `NOTES.md` (layout, grading,
findings per card) and `cd/README.TXT` (what is on the discs and how to run them).

This is a snapshot of the working copy in `F:\Claude\86Box-Next\cardtest`, where the scripts
expect to run (`build.sh` / `disc2.sh` build `out/CARDTEST.ISO` and `out/CARDTEST2.ISO`;
`third.sh` copies third-party benchmarks from the owner's local library, which is not in this
repository). Build output, test runs and third-party material are not committed.
